Up to 200 MB · .xml or .json

Leave blank for a JSON array. For {"records": [...]}, enter records. Other top-level properties repeat in every part.

Files are uploaded to this server and processed using temporary disk storage, then deleted after download or failure.

How does splitting work?

JSON: splits a top-level array, or an array under the top-level key you provide. Each output is valid JSON. Records stay in their original order.

XML: splits direct child elements of the root. Each part retains the root name, its attributes and the selected children. Nested record containers must be flattened first.

Choose “Number of files” for evenly balanced parts, or “Records per file” for a fixed maximum record count. Up to 500 output files. Non-record JSON metadata is limited to 2 MB. Splitting is by records, not bytes.

XML formatting and namespace prefixes may change. Comments, processing instructions and DTDs are not preserved; XML with mixed text between records is rejected. This tool is not for signed XML or exact byte-for-byte preservation.
