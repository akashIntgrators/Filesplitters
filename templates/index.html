How does splitting work?

Upload an .xml file or a .txt file containing XML. We validate the actual XML contents; ordinary text and JSON files cannot be split.

Each direct child of the root is treated as one record. Records are distributed evenly across your chosen number of files, in their original order. Each output retains the root name, its attributes and the selected children.

Every downloaded part has an .xml extension, even when your input uses .txt. The number of files cannot exceed the record count or 500. Parts are balanced by record count, not byte size.

XML formatting and namespace prefixes may change. Comments and processing instructions are not preserved. DTDs, entities and mixed text between root-level records are rejected. This tool is not for signed XML or exact byte-for-byte preservation.
